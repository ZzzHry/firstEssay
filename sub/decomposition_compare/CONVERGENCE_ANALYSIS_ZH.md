# 工作站/整线分解与当前算法的收敛性

## 1. 分析对象与必要区分

原模型见 problem/main.tex，工作站分解见 problem/dwcg/main.tex，整线分解见 problem/dwcg2/main.tex。本文讨论固定有限输入、原模型、原容差下的算法，不改变物理约束。

工作站列满足单站任务模式、节拍、疲劳与配置逻辑；任务唯一性、必拆、AND 前缀、线回收和共享资源由主问题协调。整线列额外满足整条线的唯一性、必拆、优先、回收等约束，主问题仅协调线凸性和共享 H/R。

以下三个结论不能互换：完整列 LP 已证最优；受限列池 IP 已证最优；原始 IP 已证最优。列生成本身首先解决 LP，整数全局证明还需要界闭合或完整整数搜索。

## 2. 松弛强度

记 P_ls 为单站整数列域，Q_l 为整线整数列域。任一 q∈Q_l 的每个站配置均属于对应 P_ls，且整线任务/优先/回收约束成立。

任一整线主问题 LP 解，可将每条线的列混合投影到各站的边缘混合：同一整线列在每站贡献相同的混合权重。线凸性保证每站凸性，线内约束经线性组合仍成立，目标和资源系数相加不变。因此整线完整 LP 的可行解投影包含于工作站完整 LP 可行域。

局部整数列的凸包又包含于对应紧凑局部 LP 约束域，故对最大化：

\[
Z_{IP}=Z_{line-IP}=Z_{station-IP}
\le Z_{line-LP}\le Z_{station-LP}\le Z_{compact-LP}.
\]

完整列 IP 等价依赖原配置双向逻辑和所有合法列完整覆盖。空站保留；整线空方案只在满足必拆/回收等局部条件时存在。

整线 LP 的界可以更紧，但不保证严格更紧，也不保证计算更快。单线 PP 可以包含该线全部任务、站点和优先关系，较少的 PP 调用可能每次更昂贵。

## 3. 精确算术下 CG 的有限终止

假设每轮 RMP 求得真正最优及其对偶；每个块均求得精确定价最大值；只加入合法、未出现过、正 reduced cost 列；不删列；局部域有限，且允许所有必要迭代完成。

任务、站点和模式有限，单站可选 assignment 数至多为每任务“不选/模式”的乘积；整线可选 assignment 数至多为每任务“不选/站点×模式”的乘积。U/H/R 由 assignments 决定，故两种列域均有限。

若存在正 reduced cost，至少添加一条新列，列池严格增长。当前 RMP 中已有列的 reduced cost 不可能严格为正，因此精确定价的正列不会只是已存在列。有限列域意味着有限次添加之后必然无正列，或此前已经终止。这个论证不要求每轮目标严格改善：退化可能使目标停滞，但新列集合仍增长。

这只是有限终止，不是多项式复杂度或实际快速性保证。最多潜在列数本身可能指数大，且整线 PP 为整数优化问题。

## 4. Phase I

工作站根 CG 使用空站列和必拆/回收人工变量建立起点；空站保证唯一性、前缀、共享资源等不被初始违反。该根节点构造不能直接替代分支节点的广义弹性 Phase I。

整线列可能不能为空，先由局部 MILP 找到每线合法列；共享资源行用人工变量恢复可行性。没有真实完整列 LP 可行解时，Phase I 最优人工和严格为正。

Phase I 的零人工量且真实硬约束 RMP 可行，才允许进入利润阶段。用完整精确定价的修复上界严格低于负可行性容差，可证明完整列 LP 不可行。初始受限 RMP 不可行、局部求解超时、未找到列均不自动证明原模型不可行。

## 5. Phase II 单调性与误差

每块凸性 Σλ=1。对最优 RMP 对偶 π，设 ρ_b=max_p(c_p−πA_p) 为包含凸性常数的最大检验数，则修复块凸性对偶得到

\[
UB_t=Z_{RMP,t}+\sum_b\max(0,\rho_b).
\]

条件是 RMP 的原始/对偶最优性、完整块覆盖、定价最大值有效和所有行系数一致。不能以最大化 PP 的 incumbent 代替尚未证最优的最大值。

加列不删列时，同一 Phase II 的 RMP 目标非下降；不同轮修复 UB 不保证逐轮下降，应取历史有效 UB 的最小值维护界。Phase I 与 Phase II 目标不同，不能接成一条利润单调曲线。

若每块 ρ_b≤ε，则完整 LP 与 RMP 的目标差最多为 Σ_b max(0,ρ_b)≤Bε。工作站 B=总站数，整线 B=线数。实际证书应保存求和后的修复界，不把单块 ε 冒充全局绝对误差。浮点 primal/dual 残差、整数容差和原始 witness 验证还需独立检查。

## 6. 原整数最优性如何获得

受限整数主问题产生的方案，经原始约束与独立数据检查后给出整数 LB。有效完整列 LP 界给出原 IP 的 UB。若 UB−LB 在已声明的绝对/相对容差内闭合，就得到原整数最优性证书。

即使仍有正 RC，也可能已经得到足以闭合整数 LB 的有效 UB，算法可提前结束；结果应记为“整数界闭合”，不伪造常规 LP 精确定价终止标志。

若完整列 LP 与整数最优之间有正间隙，单纯继续 CG 未必闭合整数 Gap。生成列的受限 IP 也可能无解，即便原 IP 可行。工作站列容易在任务覆盖、优先、回收和资源方面产生复杂拼装；整线列保证线内可行，但仍须满足跨线共享容量，也不自动保证整数可组合。

## 7. 资源档位 MILP＋DP 的证明与终止

档位 F_l(h,r) 按精确资源计数定义。每档真实合法列利润提供下界，可靠局部求解界提供上界；未证不可行的未知档位保留，未知上界按正无穷。

完整档位域覆盖所有线整数方案，且仅共享 H/R 跨线耦合时，lower DP 给可验证整数解，upper DP 给原整数问题上界。其界可比完整列 LP 更紧，因为它解决整数资源组合；因此档位 DP 的闭合不等于 CG-LP 已收敛。

如果每个有限档位最终都被精确求解或可靠证明不可行，有限个档位及有限容量 DP 将完成原整数问题的最优/不可行证明。这是条件性有限终止。

当前生产算法有总时限、单档时限以及按需选择。重复查询为冷重建，没有保证每档最后都得到精确解。因此**不保证任意输入在固定预算内闭合**；停机时必须保留未证状态和真实 Gap。调度规则改变不能改变证明来源。

## 8. 实际代码中的限制

- code/dwcg/solve.py 的根工作站 CG：完整精确定价轮才更新修复上界；超时保留部分证据，不把缺失块当零 RC。
- sub/stage9/cg_balanced.py：两阶段整线 CG；本轮所有块尝试完成后，若有未证 PP 就停止继续精确 CG；不完整轮不证明 LP 最优。可验证候选列可改善整数恢复。
- sub/stage9/balanced_bound.py：资源档位与有效经济界后处理可独立闭合整数 Gap；证书来源需区别。
- max_iterations、总墙钟、solver_error、数值不确定均可能使理论无限预算流程提前结束；这些不是收敛证明失败的数学反例，也不能被报告为已证最优。

## 9. 实验应验证的收敛现象

分别记录 Phase I 人工量、Phase II RMP 目标、历史最小有效 UB、整数 LB、最大 RC/正 RC 和、完整定价轮数、列数、PP 调用与时间。比较既包括轮数，也包括墙钟和定价成本。

如果整线在少量轮数得到紧界、工作站需要更多小 PP，这是分解结构的解释证据；如果大块整线 PP 超时，则是相反边界。单个 seed 和限时未收敛曲线不能推断完整 LP 的最终排序，也不能用受限 RMP 目标高低冒充松弛强度比较。严格排序优先由小例完整列 Oracle 验证。
