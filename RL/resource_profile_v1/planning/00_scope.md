# 本轮范围

- 项目：整线分解框架中的资源档位主动补全，resource-profile-v1。
- 模式：compose；文体：内部实验执行计划；语言：中文。
- 读者：课题研究人员与后续实施者。
- 本轮交付：实验指南、分阶段目标、配置草案、证据索引与计划检查记录。
- 本轮不执行：算法实现、实例生成、求解实验、RL 训练、论文结果更新。
- 研究对象：现有 `sub` 整线 CG＋整数恢复＋资源档位 MILP/DP 框架；不是旧工作站分解，也不是新增 B&P 搜索。
- 第一版动作：仅选择下一次查询的 `(line, human_count, robot_count)`；固定原有单次查询预算规则。
- 延后：学习预算、改变对偶价格、局部任务修复、跨节点复用、扩大任务规模。
- 保护：保留历史文件、原模型、数值政策和用户未提交材料；新增文件单独归档。沿用用户此前授权上传 GitHub，不合并 main。
- 当前基线：`e65a2b06cdf956d341a4856dc0da5f5a76e730b3`；历史性能基线不能自动视为当前重新运行结果。

采用 researchwrite 的基础材料流程；仓库内使用本目录保存规划依据，面向研究人员的主文档放在上一级，避免改动旧 RL 设计。
