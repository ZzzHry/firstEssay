# 论证链

## 科学问题

在整线 CG 和精确证书机制固定的情况下，利用跨线资源兼容性与查询历史选择局部资源档位，能否比既有规则和强确定性规则更快改善经验证的整数 LB/有效 UB？如果有，长期学习是否优于单步学习？

## 预期回答（假设）

在档位补全活跃的实例上，资源兼容性可能有助于减少无效查询；若收益显著依赖后续查询，长期学习可能进一步改善预算内整数 Gap。无收益也是可接受结果。

## 支撑链

1. E1 支持研究档位补全，E2 限制适用范围；先 P0 诊断，后决定是否训练。
2. E5 规定“学习调度、求解器证明”，先 P1 独立验证，再测速度。
3. E6 用确定性 DP 规则检验，E7 用 bandit 与 RL 区分；不能把复杂网络当必要条件。
4. E8 依赖新实例整组留出，最终全链预算比较才能支持部署收益。

## 反解释与区分实验

- 只减少 Python 开销：相同接口、固定档位重放微基准，单列策略计算成本。
- 多给后处理时间才改善：主要实验冻结 cg_fraction 与预算规则，另一分配比例必须单独标为附加实验。
- 强规则已经足够：保留该结果，暂停 RL 投入。
- 只在已知 seed34 有效：历史样本仅开发，新生成批次全部保留。
- 恢复快照省略 CG 时间：条件实验与端到端实验分开报告。
- 用预测过滤了好档位：动作屏蔽只能来自合法域和已认证状态；证明账本不变。
