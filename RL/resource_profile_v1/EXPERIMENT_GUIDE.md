## 1. 本阶段究竟研究什么

保留当前整线分解。每个列是一条拆卸线全部站点的完整任务—模式方案，线内约束已经满足；主问题协调跨线共享人工、机器人资源。CG 提供列和有效 LP 界，整数恢复或资源档位 DP 提供可执行整数方案。学习介入后处理阶段的一个决策：

> 下一次应该精确查询哪条线、恰好使用多少人工和机器人的局部整数方案？

第一版动作只有 `q=(line_id,h,r)`。不让网络修改原约束、目标、CG 对偶、数值容差或证明规则；不学习预算；不同时加入局部任务修复。后续若证明本阶段有用，再单独设计预算动作或定价控制。

与旧材料的关系：`RL/adaptive_v1` 和 2026-11-08 的组会设计主要研究候选定价/价格策略；本指南把“整数资源档位补全”设为接下来优先验证的方向，旧方案保留作为探索记录，不混合两种实验的结论。用户的 `sub/agDetail/rl.md` 中整体比较、轨迹、消融、泛化原则继续适用；其价格/触发/预算动作消融需要换成本指南的档位动作消融。

**不能预设 RL 一定有用。** stage13 的 seed34 有 31 次档位查询并参与整数闭合，支持诊断这一路径；同组 seed32/33 没有查询。对零查询实例，本策略原则上没有调度收益，最多增加接口开销。80/2 大块例的主要困难仍在原生定价，不能指望后处理调度普遍解决。

## 3. 档位、上下界与证明约定

### 3.1 查询对象

设 `P_l` 为原定义下第 l 条线的完整局部整数方案集合，定义

\[
F_l(h,r)=\max\{c(p):p\in P_l,\ H(p)=h,\ R(p)=r\}.
\]

`h,r` 是精确配置计数；人机协作需要相应两种资源。局部域包含原来的任务唯一性、必拆、AND 优先、节拍、疲劳、回收、站点和配置逻辑。档位域覆盖 `0..min(站数,全局容量)` 的所有计数对；没有已知列的档位仍可能可行。

查询返回：原生状态、局部合法列、真实利润、有效 Best Bound（若契约允许）、耗时和完整证书。该查询以原利润为目标，资源价格和凸性常数设为零。复用的是已有**局部利润上界**契约，不能据此自动引入“截断 CG 定价继续迭代”的新规则。

### 3.2 局部账本

- `ell_l(h,r)`：该档已验证列中的最大利润；没有 witness 时按负无穷，不输出伪造数值。
- `u_l(h,r)`：该档最小已认证有效上界；未知时按正无穷。
- 可靠证明局部不可行后可排除该档；超时、未找到列和异常均不等于不可行。
- 若 `u < ell - bound_consistency_tolerance`，停止升级证明，记录数值/证书冲突。

精确计数的 `F_l(h,r)` **不保证随 h/r 单调**。不能把较小档的利润当成较大档的有效下界，除非有真实合法方案；不能仅根据“多资源应当更好”删档或传播界。

### 3.3 全局整数界

各线恰好选择一个档位，满足 `Σh≤H_total, Σr≤R_total`。用 ell 做 DP 得到有 witness 的可行组合；逐项回到原始模型验证后才成为整数 LB。用 u 做完整域 DP 得到有效 UB，可与已有有效 CG/经济界取最小值。

成立条件同时包括：完整合法档位覆盖、每线恰选一份原模型可行方案、利润可加、跨线仅有这里的共享 H/R 耦合、每个有限局部上界有正确来源。学习不能改变这些条件。

上界 DP 的三种情况必须分开：

1. 无剩余资源组合：在完整覆盖及合法排除前提下，可证明整数不可行。
2. 有组合但价值为正无穷：UB 未知，JSON 用 null 加 `bound_status=unknown`；不是可行或不可行的证明。
3. 有有限上界：记录值和来源；与已验证整数 LB 闭合时，可证明原 IP 在指定浮点容差内最优。

资源 DP 闭合不意味着 Full-line-LP 已证最优；证书分别记录 `cg_lp_status` 和 `integer_proof_source`。网络预测值不进入任何界字段。

### 3.4 第一版不增加新剪枝

动作域仅屏蔽越界、已证不可行和已证最优档位。已有 incumbent、有限但未闭合的 UB、超时、低模型评分都不能屏蔽。已解决档位仍保留在证明账本中。

可把强制经过某档位的有效组合上界

\[
W^U_l(h,r)=u_l(h,r)+U_{-l}(H_{total}-h,R_{total}-r)
\]

作为排序特征。即便它能支持更强安全剪枝，第一版也暂不删除该档，避免同时引入新的剪枝契约。将某个 u 暂替换为 ell 再运行 DP 的“假设收益”，仅是排序特征，不是实际界更新。

## 4. 状态、动作和一次交互

### 4.1 状态必须是决策当时可知信息

|类别|第一版建议字段|
|---|---|
|全局|剩余时间、已验证 LB/有效 UB 及缺失标志、原始 Gap、CG 结束状态、已查询数量、各线未解决档数|
|局部档位|line/资源计数归一化、是否有列、列利润、有效上界及未知标志、尝试次数、累计耗时、上次状态|
|兼容性|是否位于当前上界路径；其他线的剩余资源 lower/upper DP；强制档位的组合潜力；能否与已有其他线 witness 组合|
|历史|最近查询的有效 LB/UB 改善、原生求解时间、是否出现新档位、停滞步数|
|线规模|任务数、站数、可执行模式比例等由输入直接获得的统计|

不要输入未来最优值、完整枚举答案、后续 solver bound、测试集表现、生成器构造 witness。无限界使用标志位与有限归一化数，不能直接把 inf 喂给网络。DP 能便宜精确计算的信息优先直接计算，网络学习未知查询收益与成本。

初版采用共享的小型档位打分网络＋全局特征，支持变长动作集合，不先实现复杂 GNN。line 编号只用于确定性并列处理，不应成为记忆产品身份的主要特征；测试线顺序置换敏感性。

### 4.2 动作与预算

动作 `q=(l,h,r)`；一次动作调用一次原生局部 MILP。共同预算规则保持

\[
b(q)=\min\{2\cdot2^{\min(attempts(q),8)},\ remaining\_algorithm\_time\}.
\]

这叫**固定预算规则**，不是“每个动作固定 2 秒”。选择重复档位会因尝试次数增加而得到更长求解时间，这是查询决策的内生影响，必须记录。首次比较不单独控制预算。归因微实验可额外将所有查询固定为 2 秒，但该实验须独立命名，不能混入生产主表。

现有 profile MILP 是冷重建。重复查询不是继续同一个未完成的 CPLEX 树；不得把重建当恢复。若未来增加持久化热启动，要作为所有策略共有的新版本重新比较。

### 4.3 交互顺序

1. 检查 deadline、账本状态和可用动作；已经完成整数证明则停止。
2. 生成当前可见特征；选择合法档位；日志保留 action mask 和策略评分。
3. 按共同规则执行查询；原生状态与返回列独立核验。
4. 只将经验证的列/界更新到账本；保持所有未知档位。
5. 重新计算 DP、验证整数 witness、更新 LB/UB；保存一次完整事务。
6. 生成学习反馈，再进入下一步。未提交成功的证明不成为正式结果。

策略异常时记录异常，可按预先约定回退到确定性规则；不能悄悄回退后称纯 RL 成功。求解器或证书矛盾不能靠策略回退掩盖，保留安全已提交结果并结束未证。

## 5. 对比策略：逐层确认学习的作用

|编号|方法|用途|
|---|---|---|
|D0|完整生产分解＋原上界路径/最少尝试规则|不可缺少的主基线|
|D1|局部不确定性/缺口优先；未知优先且按尝试数防止一直重复|检验只看局部价值是否足够|
|D2|DP 兼容性规则|检验跨线结构本身是否有效|
|D3|DP 兼容性＋已观测成本规则|学习前的强非学习基线|
|B|上下文 bandit|检验单步学习是否足够|
|R|仅档位选择的长期 RL（初选 masked PPO）|检验延迟收益|
|C|Compact CPLEX-IP|保留原课题的直接求解对照|

D2/D3 的候选范围与学习方法使用相同合法域。D0 选择当前上界路径是它的策略规则，不是把其他档位从共同证明域中删除。各方法保留完全相同的 CG、局部 MILP、界计算、整数验证和证书后端。

D2 初版优先级：有机会补齐当前缺失的整数组合、可改善已有组合利润、位于最优/并列乐观组合且局部界未闭合；再按可计算的潜力、尝试次数和固定 `(line,h,r)` 顺序处理并列。P2 开始前将其精确评分公式写入 frozen_protocol，不能根据最终测试调权重。D3 使用相同潜力及仅来自此前观测的时间估计；未查询档用训练/开发先验，不偷看后续真实耗时。

只将验证集选出的最强规则送入主要 RL 对比；其他规则保留完整开发结果。不得只与较弱 D1 比较来证明学习有效。

## 6. 为什么先 bandit，再 RL

若每次查询的价值能由当前局部信息与即时改善决定，bandit 或强规则可能已经足够。只有观察到以下现象，长期 RL 才有明确动机：

- 必须先补一条线，再补另一条线，才出现可行资源组合；第一次查询即时 LB 不变。
- 多条并列乐观路径导致只收紧一个档位时 UB 不变，连续处理相关档位后才降低全局 UB。
- 某查询提供有用 witness，却需要后续组合才能体现整数价值。

这些是待证机制，不是现有实验结论。用相同状态的分叉试验检验 1–2 步查询的后果，限制为开发数据；记录额外标签成本。不得靠同一条历史轨迹重排序来臆造另一个策略的求解时间。

初版奖励草案采用“有效界改善＋时间内 Gap 面积”，而不是新列数或 RC 总和。定义有限 LB/UB 时

\[
g_t=\min\{1,\max(0,U_t-L_t)/\max(1,|L_t|)\},\quad Q_t=1-g_t.
\]

无 incumbent 或无有限 UB 时 `g=1`；已认证最优/不可行后 `g=0`。若界矛盾超过容差，报错，不能通过 max 掩盖。该截断量只用于奖励/补充面积指标，正式报告保留原始 Gap 和缺失状态。

建议每步反馈：

\[
r_t=(Q_{t+1}-Q_t)-\frac{\Delta t}{T}g_t
       +0.05\,\mathbf1_{首次验证整数解}
       +0.10\,\mathbf1_{首次完成有效全局证明}.
\]

权重为待开发验证的初值；训练/验证阶段可修订并留版本，最终测试前锁定。有限墙钟 episode 初选 `gamma=1`，避免不同查询时长被误当相同步长；累计时间项包含特征、策略、DP、求解及必要证据处理。异常提前结束按剩余预算记未解决损失，不能使“崩溃越早奖励越好”。

bandit 使用同一合法状态和动作，学习下一步有效改善及所需时间；RL 学习累计回报。P3/P4 同时报告非学习指标，不能以训练 reward 上升代替求解收益。

## 7. 独立正确性与故障测试清单

所有性能实验的前置条件是 P1。完整枚举仅用于极小 Oracle，不进入正式策略可见状态。

|测试组|必须覆盖|验收|
|---|---|---|
|局部域|H/R/J、疲劳、AND、必拆、回收、空方案、精确 h/r|所有返回列均可行；有限 UB 不低于 Oracle 最优值；仅声称最优时要求目标相等，声称不可行时要求 Oracle 无解；超时未知不强求闭合|
|全局组合|资源紧张、多线、负利润/零利润、多重最优|DP 与完整列 IP、Compact-IP 一致|
|缺失状态|无列、未知 UB、仅有 incumbent、超时有有效 bound|未知不变不可行；incumbent 不变上界|
|整数补全|LP 可行/IP 不可行、受限列池缺中间档、非正 RC 的有用整数列|不会沿用“只加正 RC”把修复列丢弃；真实整数验证通过|
|策略顺序|旧规则封装、不同顺序、重复动作、线顺序置换|旧规则数学结果一致；任意顺序的界安全，不要求限时目标相同|
|伪造拒绝|丢档位、篡改利润/资源/原生状态/上界、过期对偶、不完整 CG 定价、假最优|独立重放明确拒绝|
|时限与事务|查询中断、写盘中断、只剩摘要、损坏证据、策略异常|只接受已校验完整事务；不完整证明不升级|
|隔离|不同实例/方法的账本、缓存、随机种子|不共享真实 solver 状态或未来标签|

教学用“中间档缺失”例可构造成：A 线人工作业的合法 `(h,profit)` 为 `(0,0),(1,8),(2,20)`；B 线必须占 1 人工、利润 0；全局人工 2。A 线中间档对线性人工价格从不严格最优，却是组合整数最优所需。理论目标为 IP 8、完整 LP 10，仅端点的受限 IP 为 0。**这是待编码的构造，不是实测结果**；P1 需给出满足原模型的实例 JSON、完整枚举和三种求解证据后才能标 PASS。

容差沿用当前 NumericPolicy：LP primal/dual 1e-8；pricing/branch integrality 1e-7；column local 1e-8；RC/人工量 1e-7；整数原约束检查 1e-6；界一致性/绝对最优 1e-5；相对最优 1e-8。每项职责不同，不为通过测试统一放宽。

|最终测试|24 个新基础输入，建议 4 结构层×6|统一冻结评测；数量是计划，不是已生成|

四个最终结构层建议为：①同分布中等块、资源宽松；②同分布中等块、资源紧张；③每线规模近似固定、增加线数；④线数较少、每线任务增加的困难大块。具体站数、任务量、必拆比例和生成器参数在 P2 后锁定；不能先看测试结果再选择“好看的”层。正式规模不默认扩到 160/200。

训练/验证/测试按 `base_instance_id` 分组；同一产品图、任务时长/模式数据派生出的资源变体、快照、轨迹和标签全在同组。若多个 seed 复用了同一基础产品，按产品族分组，而非仅按 seed。划分先于标签生成，哈希去重并保留 split_manifest。只有真正未见产品族才能称产品泛化；仅新随机实例则写同分布泛化。

整个预注册批次均报告，包括零查询、超时和失败。可另报告“D0 在指定预算下触发档位查询”的子组，但必须同时给出全体结果，并明确此为基线定义的诊断分层，不用于淘汰测试实例。

## 9. 两类实验必须分开

**条件机制实验**：恢复同一个已认证 CG 输出与档位账本，从相同非原生状态开始；各策略重新创建相同局部模型，以相同剩余预算查询。用于比较查询次序、兼容性特征和局部成本。生成快照的成本另计，不能把该剩余时间写成完整求解时间。不能继承只有某方法享有的 CPLEX 内部搜索状态。

**端到端实验**：从冻结输入文件开始，计入进程启动、依赖/模型加载、CG、档位查询、整数验证、策略推理、DP、必要证书落盘、父进程轻量核验和最终结果生成。它才回答对完整 D0 与 Compact 的实际增益。

固定同快照/同档位调用的微基准用于解释接口开销；策略轨迹不同导致的求解工作量变化是算法效果，不称接口加速。顺序试验改变 solver 历史的影响也须记录，不能离线拼接不同轨迹的时间。

P2 单独记账：端到端 12×4×30 秒共 24 分钟；最多 6 个开发快照×4 策略×30 秒共 12 分钟；最多 6 个状态×2 条短分叉路径×10 秒共 2 分钟（每路径最多两次查询，预算不足则记录未完成）。尽量从本轮 D0 记录取得快照，若必须补采，另限 3×60 秒共 3 分钟。全部调用的名义预算最多 41 分钟，准备/深度核验成本另计。条件试验不能与端到端记录混为一份 run。

## 10. 时间预算、证据与统计

建议先 30 秒开发 pilot，视机制空间在**开发集**选择 60 或 120 秒复验；主测试默认候选 120 秒，测试前锁定。不直接启动 600/3600 秒全矩阵。600 秒与 120 秒实验分开比较；CPLEX 未证记 `>实际截止秒数` 或 censored，不改写为 3600 秒实测。

统一 `t0` 为父进程准备启动本次 worker 时，结束为必要结果提交及轻量核验完成；策略模型加载、CPU 推理和特征构造都计时。沿用 5 秒收尾预留，并在 P1 核查其是否足够。预算 10 秒的微例只用于功能验证，不用于公平速度结论。Windows/native solve 的不可抢占越界如实报告，不称硬实时保证。

至少记录互不重叠的顶层耗时：启动/导入、CG、profile MILP、DP/特征、策略、独立整数验证、证书事务、其他；内部再细分建模/目标更新/原生求解/读回。顶层和加残差应能对账总墙钟，不同时相加父计时与其子计时。首次整数解时间基于**完成验证**的事件，并区分算法发现和提交完成。

训练、离线标签、深度完整重放和 Oracle 成本单列；部署必需的在线检查不能搬到计时之外。正式结果只引用提交完成并有哈希的证据。安全摘要不是可恢复完整搜索；本阶段不新增恢复能力的主张。

主要结果字段：方法/源码/模型/输入哈希，求解器/线程/seed/容差，预算，status，整数 witness，LB，UB/来源，原始 absolute/relative Gap，整数最优/不可行证明标志，首次已验证整数解时间，证明时间或删失标志，E2E，超预算，CG 轮数，CG PP 次数，profile 次数，唯一档位数，新列数，耗时分解，证据大小与重放状态。

统计原则：

- 同一实例是配对单位；同一轨迹中的各查询不是独立样本。
- 全部实例报告可行率、证明率、超时/异常率；未知 LB/UB/Gap 保留 missing 及原因。
- 对双方均已证者可报告配对时间比，同时必须报告全体的预算内证明比例曲线，不能只报成功子集均时。
- 固定时刻报告 LB/UB/Gap；可额外报告截断 Gap 面积，但不能用它掩盖无可行解或未知界比例。
- 多训练 seed 的结果先按实例聚合，再用按实例/产品族成组的 bootstrap 区间；若样本太小只给描述统计，不宣称显著。
- 最终 RL 至少 3 个独立训练 seed；模型由验证集选，测试结果不反向调参。先完成一个模型的 smoke，再开展其余重复。
- 同硬件单线程串行配对，实例块内随机/平衡运行方法顺序，避免温度、缓存、后台负载使一种方法固定占优。

## 11. 消融和论文可用结论

只在完整 R 确有价值时开展少量必要消融，不先铺满组合。

|消融|保持不变|回答的问题|
|---|---|---|
|去掉跨线 DP 兼容性特征|动作域、MILP、预算、证明|是否利用了问题结构，而非局部缺口|
|去掉近期查询历史|当前账本、网络容量尽量可比|是否依赖历史成本/停滞信息|
|改为即时收益学习|同状态/动作/后端|长期序列是否比 bandit 有额外价值|
|换成局部利润改善奖励|模型与环境|全局整数界奖励是否优于局部导向|

特征/奖励消融要重新训练，不能仅在测试时删除输入。所有消融保留原数学验证；不能去掉证书来制造速度收益。

论文结论按证据逐级成立：

1. D0 对 Compact 的历史优势只支撑分解框架；R 对 Compact 更好仍不能单独证明 RL 有效。
2. R 优于完整 D0 和验证选出的最强规则，才支持学习的额外价值。
3. R 进一步优于同信息 bandit，且延迟收益/消融证据一致，才支持长期决策价值。
4. 新实例完整留出测试有一致收益，才支持对应范围的泛化；不自动扩展到更大块或所有资源配置。

优先图：全体证明比例—时间；已验证 LB/有效 UB/Gap 的代表轨迹＋全体汇总；配对性能分布；查询类型与资源紧张度；非重叠耗时；必要消融。CG 迭代数、列数、profile 次数是解释指标，不能替代墙钟和整数质量。

创新表述应落在“利用资源兼容性主动获取整数相关局部方案/证据，并以有效全局界反馈调度”。已有 RL 列选择、对偶稳定化、启发式选择研究，文献见 planning/01_research_canon.md；本轮仅做定位，正式论文前仍需完整查新。既有 DP 本身、简单整数奖励或泛称 CG＋RL 不单独作为新贡献。
